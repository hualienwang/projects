# 瓊林圖書進銷存系統 - 數據可視化前端

## 📖 概述

本前端項目是基於 Vue3 + Vite + Chart.js 開發的數據可視化系統，對接後端 LangGraph 工作流 API，提供豐富的數據分析圖表和基於角色的訪問控制（RBAC）。

## 🚀 快速開始

### 環境要求

- Node.js >= 16.x
- npm >= 8.x
- 後端服務器已啟動（http://localhost:8000）

### 安裝依賴

```bash
cd frontend
npm install
```

### 啟動開發服務器

```bash
npm run dev
```

訪問 http://localhost:3000 查看應用。

### 構建生產版本

```bash
npm run build
```

## 📊 功能特性

### 1. 數據可視化圖表

- **銷售趨勢圖**: 按日期統計銷售額和訂單數
- **商品銷售排行**: 統計商品銷售數量排行
- **庫存狀態分佈**: 正常/低庫存/缺貨統計
- **客戶消費分析**: 客戶消費金額排行
- **供應商採購統計**: 供應商商品數量和成本

### 2. 權限管理

實現基於角色的訪問控制（RBAC）：

- **admin**: 系統管理員，所有權限
- **manager**: 經理，訪問銷售趨勢、商品排行、庫存分佈、客戶分析
- **staff**: 員工，訪問銷售趨勢、商品排行
- **viewer**: 查看者，只讀，訪問銷售趨勢

### 3. 交互功能

- 角色切換
- 時間範圍選擇
- 數據刷新
- 圖表交互（懸停、點擊等）

## 🔑 使用示例

### 角色切換

在頁面右上角的下拉菜單中選擇不同角色，查看不同權限下的圖表：

```
系統管理員 → 經理 → 員工 → 查看者
```

### 圖表過濾

每個圖表都支持時間範圍和數據量選擇：

- 銷售趨勢: 7天 / 30天 / 90天
- 商品排行: Top 5 / Top 10 / Top 20
- 客戶分析: Top 5 / Top 10 / Top 20

## 🐛 常見問題

### 1. CORS 錯誤

確保後端服務器已啟動（http://localhost:8000）

### 2. 權限不足

檢查當前用戶角色是否具有訪問該圖表的權限

### 3. 圖表不顯示

打開瀏覽器控制台查看錯誤信息
